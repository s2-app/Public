# Ss Tools

個人開発した Windows 向けユーティリティ（**Ss シリーズ**）のコンパイル済みアプリを配布しています。

- 対象OS: **Windows 10 / 11 (x64)**
- 形式: **自己完結単体 exe**（.NET ランタイムのインストール不要）
- ソースコードは非公開です。ここでは実行ファイルのみを配布します。

## ダウンロード

最新版は **[Releases](../../releases)** から入手できます。

各アプリの zip をダウンロードして展開し、中の `.exe` を実行するだけで動作します。

## 収録アプリ（v1.0.0）


| アプリ | 概要 |
|---|---|
| SsDbClient | SQL Server / Oracle / SQLite / ODBC / OleDb に対応した汎用DBクライアントです。<br>・SQL実行、実行計画、トランザクション、コミット、ロールバック対応<br>・複数のSQLの一括実行（GO区切り・複数の結果表示）、パラメータ（バインド変数）指定、実行の中断・タイムアウト、危険なSQLの実行前確認<br>・接続情報の暗号化保存、接続先ごとの色分け表示<br>・データの一覧表示・更新・レコードの追加/変更/削除、BLOB表示(テキスト、画像、Byte配列、BASE64)、集計（グラフ表示付き）<br>・各種DB定義表示（テーブル、ビュー、プロシージャーなど）<br>・各種DB定義は設定により自由に追加、表示内容変更可能<br>・データ一括出力、データ一括取込、データ一括自動作成 |
| SsFileList | ファイルを各種条件で検索し、リスト化します。<br>・フォルダ名・ファイル名・ファイル内まで検索可能<br>・取得情報を指定可能（ファイル属性、バージョン、文字コード、ハッシュ値、ブロックなど）<br>・ファイル属性の一括変更、ブロックの一括解除が可能<br>・ファイルリストの出力（リリース時のエビデンスなどに使用可能） |
| SsAudioSwitcher | オーディオデバイスをワンクリックで切り替えます。<br>・トレイアイコンで左クリックでデバイス切り替え、右クリックでミキサー画面を表示<br>・入力出力デバイスを連動して切り替えが可能<br>・出力・入力それぞれにホットキーを割り当て循環切替が可能<br>・ミキサー画面で音量調整・ミュートも操作可能 |
| SsFileSplitter | 大容量ファイルを指定サイズ／個数で分割し、分割ファイルと結合用スクリプトを出力します。<br>・分割数 or 分割サイズ（KB/MB/GB単位）を指定<br>・分割前にプレビューで分割数・サイズを確認可能<br>・分割後の結合用バッチファイルを自動生成 |
| SsSwitchBot | SwitchBot API を使いデバイス・シーンを操作します。<br>・デバイス一覧表示、個別デバイスへのコマンド送信<br>・シーンの一覧・実行、グループ編集<br>・タスクトレイに常駐可能<br>・コマンドライン実行にも対応（SsSwitchBot.exe "シーン名" や "デバイス名" "ボタン名" でショートカットから呼び出し可能） |
| SsMsgBoxTest | メッセージを表示・確認できる開発支援ツールです。<br>・アイコン・ボタン構成・タイトル・メッセージを指定して表示<br>・よくあるパターン（エラー／警告／インフォメーション／確認）をワンクリックで設定<br>・実際に表示した際の戻り値（OK/Cancel等）を確認可能 |
| SsStepCounter | ソースコードのステップ数（行数）をカウント・比較するツールです。<br>・コード行／コメント行／空白行を拡張子別のコメント規則で判定しカウント<br>・変更前後のフォルダ／ファイルを比較し、新規／変更／削除／未変更の行数を集計<br>・拡張子別のコメント規則（単一行／複数行）は設定ファイルで自由にカスタマイズ可能 |

## 使い方

1. Releases から対象アプリの `*-win-x64.zip` をダウンロード
2. 任意のフォルダに展開
3. `.exe` をダブルクリックで起動

> ⚠️ 初回起動時に SmartScreen の警告が出る場合があります（署名なしのため）。「詳細情報」→「実行」で起動できます。
